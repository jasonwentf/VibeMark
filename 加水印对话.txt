Gemini 添加水印的方式
Gemini 通过以下方式添加水印：

watermarked = α × logo + (1 - α) × original
其中：

watermarked: 带水印的像素值
α: Alpha 通道值 (0.0-1.0)
logo: 水印 logo 的颜色值（白色 = 255）
original: 原始像素值
反向求解移除水印
为了去除水印，可以反向求解如下：

original = (watermarked - α × logo) / (1 - α)
         = (watermarked - alpha_map) / (1 - α)
通过在纯色背景上捕获水印，我们可以重建 Alpha 通道，然后应用反向公式恢复原始图像

思路 2（更“自适应”）：水印尺寸与边距按比例缩放

如果你允许用户输出任意尺寸（不只 1K/2K/4K），那你可以定义：

scale = min(W,H) / base（比如 base=1024）

wmSize = round(baseWmSize * scale)

margin = round(baseMargin * scale)

优点：不用为每个尺寸做配置表。
缺点：不一定与“厂商原始策略”完全一致（但一般看起来合理）。

你要做“原始水印复刻/合规标识”，我更推荐思路 1：先标准化输出，再用厂商配置表贴，这样最符合“各家模型常见出图规格”。

6) 你描述的功能流程，我给你整理成“可直接 vibe coding 的里程碑计划”

下面每个里程碑都能单独跑起来、随时可回退，不会陷入“一口气写完整个前端”的崩溃模式。

里程碑 0：项目骨架（1 个晚上）

目标：页面能打开、左右分栏、Step1/2/3 可以切换（即使没功能）。
交付：

左侧：上传区 + 预览 canvas + 缩略图列表（占位）

右侧：stepper（步骤按钮）+ 当前步骤的表单区域

里程碑 1：输入系统（上传/拖拽/粘贴/批量）

目标：能把多张图读进来，左侧显示缩略图，点缩略图切换预览。
实现要点：

<input type="file" multiple accept="image/*">

drag&drop：监听 dragover/drop

paste：监听 paste，从 clipboard items 里取 image

解码用 createImageBitmap，生成缩略图 preview

里程碑 2：Resize & 裁剪（你说的 Step1）

目标：用户选分辨率 + 宽高比 + 输出格式，你用“cover 策略”缩放后中心裁剪；预览实时更新。
实现要点（概念）：

先算目标 targetW/targetH

cover 缩放：scale = max(targetW/srcW, targetH/srcH)

计算裁剪源区域（sx/sy/sw/sh），再 drawImage 到目标 canvas

输出格式：PNG/JPEG/WebP 对应 toBlob(type, quality)

里程碑 3：水印模板系统（核心）

目标：下拉选择厂商/版本/角落位置，点击“添加水印”，左侧看到结果。
实现要点：

设计一个 watermarkCatalog（配置表）：

vendor

variants（新版/旧版、48/96、左上/右下…）

anchor（br/tl）

marginX/marginY

wmImage（RGBA PNG）

贴水印逻辑：

先把（可能 resize 后的）图渲染到 output canvas

再按 anchor+margin 计算 (x,y)

ctx.drawImage(wmPng, x, y, wmW, wmH)

Gemini 的“按尺寸选择 48×48/96×96 + 固定边距定位”的规则在该仓库 README 里写得很明确，你做 catalog 时就按这个思想扩展到各家即可。

里程碑 4：批量导出与体验打磨

目标：批量处理 + 一键下载（单张直接下载；多张打 ZIP）。
实现要点：

里程碑 5：模板生产管线（你自己的“工具箱护城河”）

目标：你把“黑底/白底水印样本”一键转成 RGBA 模板，并自动裁出 tight bounding box。
实现要点（概念）：

生成 RGBA

自动裁剪：找 alpha>阈值 的最小包围盒，裁出来保存成模板 PNG

输出：vendor/version/size/anchor.png + catalog.json
